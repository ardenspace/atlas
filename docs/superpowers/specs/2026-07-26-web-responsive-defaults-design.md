# atlas web: 반응형·디폴트 선택·최근 활동순 정렬 설계

2026-07-26. 브레인스토밍 합의본.

## 목표

1. 열자마자 최신 대화가 보인다 (PC): 첫 프로젝트·최신 스레드 자동 선택.
2. 목록이 "최근에 쓴 순서"로 정렬된다.
3. 모바일(≤768px)에서 목록 → 채팅방 드릴다운으로 쓸 수 있다.
4. 스크롤바가 테마에 맞게 커스텀된다.

라우터는 도입하지 않는다 (딥링크 니즈 없음 — Access 뒤 3인용 도구). 미디어쿼리 + 뷰 상태로 구현하고, 채팅방 진입 시 `history.pushState`로 폰 백 제스처만 지원한다.

## 1. 정렬 — 백엔드 (스키마 변경 없음)

- `GET /api/projects`: 하위 스레드의 마지막 메시지 시각 · 문서 `updated_at` · 프로젝트 `created_at` 중 최신값 내림차순.
- `GET /api/projects/{id}` 의 threads: 마지막 메시지 시각(없으면 스레드 `created_at`) 내림차순.
- `last_activity` 필드는 응답에 노출하지 않는다 — 정렬만.
- 채팅 전송이 스레드 목록 캐시를 강제 갱신하지 않는다: 순서는 다음 목록 refetch 때 반영 (대화 중 사이드바 들썩임 방지).

## 2. 디폴트 선택 — PC

- 프로젝트 목록 로드 후 선택이 없으면(null) 첫 번째 자동 선택.
- 스레드 목록 로드 후 선택이 없으면 첫 번째 **비아카이브** 스레드 자동 선택.
- 사용자가 명시적으로 바꾼 선택에는 개입하지 않는다. 선택된 항목이 삭제되면 다시 디폴트 로직이 잡는다.
- 모바일에서는 스레드 디폴트가 **하이라이트만** 하고 채팅방 자동 진입은 하지 않는다.

## 3. 모바일 (≤768px) — 2화면 드릴다운

- **home**: 사이드바 내용 그대로 (프로젝트 목록 → 스레드 목록). 스레드 탭 → chat 진입.
- **chat**: 풀스크린 채팅. 헤더에 `←`(home 복귀) + `문서` 버튼.
  - `문서` 버튼 → **하단 시트**로 DocsPanel(문서 목록·컨텍스트 체크·예산 게이지·정착 버튼) 표시.
  - 정착·문서 편집은 기존 전체화면 오버레이 재사용.
- 진입 시 `pushState`, `popstate` 수신 시 home 복귀 (폰 백 제스처/뒤로가기 대응).
- 브레이크포인트 768px, `matchMedia` 훅으로 판별.

## 4. 스크롤바 커스텀 (전역)

- WebKit: 폭 8px, 트랙 투명, 썸 `--line` 라운드, 호버 시 밝게. Firefox: `scrollbar-width: thin`.

## 5. 테스트

- 서버 pytest: 스레드 정렬(메시지 추가 시 순서 변동), 프로젝트 정렬(활동 기준) 각 1개 이상.
- 웹 vitest+RTL: PC 디폴트 선택, 모바일 드릴다운(home→chat→back), 하단 시트 열기. `matchMedia` 모킹. 기존 테스트 50개 유지.
